Version 1.5. Find and replace, typing that continues your lists and capitalizes your sentences, every Markdown file extension, and a preview that comes back on its own.

FIND AND REPLACE
• ⌘F opens a find bar over the text you are writing. ⌥⌘F brings the Replace field with it, ⌘G and ⇧⌘G step through the matches, and ⌘E searches for whatever is selected. The rows live in Edit ▸ Find.
• Matching is plain text, ignoring case, and it wraps round the end of the document. There are no regular expressions.
• The find bar belongs to the editor, so it searches your Markdown source and not the rendered page beside it. In Preview there is no editor on screen and nothing to search.
• Replace All is a single undo step: one ⌘Z takes the whole run back, rather than one match at a time. A replace marks the document edited, so it autosaves exactly as typing does.
• The writer-mode book window has it too, on the article you are editing and on that article's own undo stack.

TYPING
• Return now continues what you are writing: the next bullet, number or task box of a list, the marker of a quoted block, a fresh row of a table. On an empty item it ends the list instead, and a nested empty item steps out one level.
• The first letter of every line and of every sentence is capitalized, and it is Markdown-aware. It never happens inside a code fence, a table cell, inline code or math, a URL, or after an abbreviation or an initial.
• A name that has to stay lowercase at the start of a sentence, md or npm, needs no fight: delete the capital md wrote and type the letter again, and it stays lowercase. Undo right after a capital takes just the capital back, as a step of its own.
• Shift-Return is always a plain newline.
• Both rules are switches in Edit ▸ Typing, on by default. Flip one and every open window follows at once.

EVERY MARKDOWN SPELLING OPENS
• Besides .md and .markdown, md now opens and saves .mdown, .markdn, .mdtext, .mdtxt, .mkd, .mkdn, .mdwn and .mkdown, the spellings other editors and older tooling have used over the years. A file keeps whichever extension it came with.
• PlantUML files open under .iuml and .pu as well as .puml and .plantuml.
• Three of those spellings were listed before and never actually worked. macOS declares the Markdown file type itself, and an app's copy of a type the system already owns is registered inactive, so .mdown, .markdn and .mdtext quietly never offered md in the Finder's Open With menu. They are now declared under a type md owns, which the system honours.
• In the Save panel's format popup the extra spellings appear as one entry, "Markdown Document (other extensions)". A new document is still a .md.

A PREVIEW THAT COMES BACK
• The preview is drawn inside a web content process of its own, and that process can be killed from under it: by memory pressure, by a system update, or by a diagram that runs the layout engine out of room. The pane used to go blank and stay blank, with no hint that the document itself was fine.
• It now loads itself again. If the same document kills it a second time with no successful render in between, md stops rather than looping and says so in one quiet line on the page. That one line is the whole of the recovery, and the next edit to the document tries again by itself.
• A preview that is merely slow is left alone. A long PlantUML or Graphviz layout looks exactly like a hung process, and reloading would kill a drawing that was about to appear.
