Version 1.4 - charts drawn from a formula, and documents that reopen where you left off.

PLOTS
- A fenced block tagged plot is now drawn as a chart. One line per curve - sin(x), or envelope = exp(-abs(x)/5) to give it a name for the legend - and any number of them share the figure, each in its own colour.
- Functions of x, parametric curves written (cos(t), sin(t)) for t in 0..2*pi, and measured points typed in as points: 0,0 1,2 2,1.
- x: and y: set the window, and y fits itself to the curve unless you say otherwise. title, xlabel, ylabel, legend, grid, axes, width, height and samples set the rest.
- The usual arithmetic and comparisons, the constants pi and e, and the functions you would expect: sin cos tan asin acos atan sinh cosh tanh asinh acosh atanh sqrt cbrt abs exp exp2 ln log2 log10 floor ceil round atan2 pow hypot.
- md draws the figure itself, in code. No engine sits behind it and there is nothing to fetch: it added nothing at all to what the app carries, where each of the diagram languages beside it - Mermaid, Graphviz and PlantUML - is an engine of several megabytes built in. A document whose figures are all plots loads no engine whatever.
- The drawing is a real vector and travels with the page - the preview, print, an exported PDF, an exported HTML page, the File menu's Export Diagram as SVG, which now offers plots beside Mermaid, Graphviz and PlantUML, and an exported EPUB, where a plot stays a vector rather than becoming a picture of one, as the other figures still do. A LaTeX export keeps the block's source under a comment, the same treatment a Mermaid diagram gets, so there is no chart in the .tex.
- A block that cannot be read never leaves a hole in the page: one plot: line says what is wrong, with your own text still under it.
- A figure is redrawn only when its own text changes, so writing prose around a page of charts leaves them all standing.

WHERE YOU LEFT OFF
- md now remembers, for each file, whether you last had it in Edit, Split or Preview, and opens it there next time - the notes you write in stay in Edit, the reference you only read stays in Preview, with no trip to the View menu.
- The memory follows the document rather than the window: it holds after you quit md, and whichever window the file opens in next. The last 200 documents you opened are remembered, on this Mac, and nothing is sent anywhere.
- A document md has not seen before still opens in Split, exactly as before, and a new one still opens in Edit. Rename or move a file in the Finder and it simply starts over.
- Books are left out of this on purpose: a book keeps one layout throughout, so stepping from one chapter to the next never changes the view under you. Zen mode stays per-window, as it was.
