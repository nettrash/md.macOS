md is a Markdown editor and live previewer for the Mac. This update (1.3) adds richer content — chemistry, syntax-highlighted code, Graphviz diagrams, footnotes, front matter and CSV/TSV tables — and several new exports: HTML, LaTeX, single-document EPUB, diagram-to-SVG, TextBundle, and a choice of page size for the PDF.

1. ACCESS — NOTHING TO SET UP
No account, no sign-in, no registration, no in-app purchases, no subscriptions. Every feature works the moment the app launches, so no demo credentials exist or are needed.

No test file is needed: the app ships with sample documents. Open File, Examples and pick any of them (Welcome, Formatting, Tables, Code, Images, Math, Diagrams, Writer Tools).

2. A THREE-MINUTE WALKTHROUGH OF WHAT IS NEW
a) File, Examples — open Math to see LaTeX and mhchem chemistry, Diagrams to see Mermaid, Graphviz and PlantUML, and Code to see syntax highlighting. All are drawn on the Mac, offline, by the bundled engines — nothing is fetched to render them.
b) The Share menu (and File menu) now offers, beside Export as PDF: a page-size choice (A4, A5, US Letter, US Legal, or a paperback trim), Export as HTML, Export as EPUB, Export as LaTeX, Export as TextBundle, and Export Diagram as SVG. Each writes a file through the standard save panel.
c) File, Print (Command-P) — prints real A4 pages. The Go menu jumps to any heading and lists the author's private notes.
d) File, Examples, "Example Book…" — unpacks a small sample book to a folder you choose and opens the book window: chapters and articles in the sidebar, the selected article beside them. The book's share commands compile the whole book to PDF (at the chosen page size) or EPUB.

A book is nothing more than a folder the user picks: its subfolders are chapters, its Markdown files are articles. The app creates no hidden files or sidecar metadata.

3. PURPOSE AND AUDIENCE
Writers, developers and students who keep notes, documentation or a book in plain Markdown files and want to see, print and export the finished page. Nothing is shared, published or hosted anywhere, so there is nothing to moderate, report or block.

4. NETWORK AND EXTERNAL SERVICES
The app contacts no servers of ours; there are none. It has no analytics, no advertising, no tracking, and it collects no data (the Privacy Nutrition Label answer is "Data Not Collected").

The sandbox carries the network-client entitlement for two reasons. First, WKWebView — which draws the preview and produces the printed page, the PDF and the EPUB — will not launch inside the App Sandbox without it. Second, if a document references an image by remote URL, the renderer fetches it so it can be shown and printed, from the host named in the user's own document. Nothing else is ever sent or fetched.

5. NO DOWNLOADED CODE (2.5.2)
Math, chemistry, diagrams and code highlighting are drawn by open-source JavaScript engines bundled inside the app and served to WKWebView from a private, offline scheme: KaTeX (with its mhchem extension), Mermaid, Graphviz, PlantUML, and highlight.js. No executable code is downloaded or updated at runtime, and no interpreted code comes from any server. There are no third-party Swift packages or SDKs.

6. PERMISSIONS
None are requested: no camera, microphone, location, contacts, calendars, or tracking prompt. The app is sandboxed with user-selected file access (the documents the user opens or saves, and the folder chosen as a book), the network-client entitlement described above, and printing.

7. REGIONAL DIFFERENCES, REGULATED CONTENT
None. The app behaves identically everywhere, contains no regulated or age-restricted content, and includes no third-party trademarked material beyond the open-source engines named above, each bundled under its own open-source licence.

Encryption: ITSAppUsesNonExemptEncryption is false — the app implements no encryption.

Minimum system: macOS 14. The source code and the privacy policy are public.
